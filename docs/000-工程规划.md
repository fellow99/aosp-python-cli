## 1. 背景与定位

### 1.1 一句话定位

**以 AAR 形式发布的、Android 版 `python` 命令行可执行**——基于 PEP 738（CPython 3.13+
官方 Android 支持）交叉编译的 `libpython_cli.so`（arm64-v8a，exec 型 PIE），扩展模块全静态，
assets 随包纯 Python stdlib + ensurepip + CA bundle。终端里提供 `python` / `pip` 命令。

### 1.2 为什么需要它

- 原生 Android 没有 python（`/system/bin` 只有 mksh 与 toybox）；
- 终端（PTY）需要**独立进程**的 python 解释器，而不是进程内嵌入；
- CPython 3.13+ 官方支持 Android 交叉编译（PEP 738），不再是社区补丁形态。

### 1.3 边界

| 在范围内 | 不在范围内 |
|---|---|
| `libpython_cli.so` 的 PEP 738 交叉编译、exec 门禁、AAR 打包、发布 | 任何嵌入 API / 进程内 libpython（未来另立 `-runtime` 线） |
| stdlib/ensurepip/CA 的随包与 sha256 出处记录 | pip 安装 sdist 包的本地编译（设备无编译器，能力边界） |
| 版本事实源 `python-cli.lock.json`（独立 semver） | python 环境管理（venv 组合由消费方/环境引导层实现） |

## 2. 版本规则

- 制品版本 = CPython 上游版本，**独立 semver**，与 node 系无配对；
- 升级 = lock 增项 + CI 重新构建（镜像 pty 的 release 纪律）。

## 3. 技术方案

### 3.1 制品形态

```
python-cli-<ver>.aar
├── jni/arm64-v8a/libpython_cli.so   # exec 型 PIE（静态扩展，16KB 对齐）
└── assets/python-bridge-tools/…     # Lib/ 纯 py stdlib + ensurepip wheels + cacert.pem
```

- 打包：**`useLegacyPackaging=true`**（exec 要求物理落盘；targetSdk≥29 SELinux 禁止从
  可写数据目录 exec）；
- **扩展模块全静态**（`Modules/Setup.local` `*static*`）：规避 filesDir 不可 dlopen 的平台
  禁令——动态扩展形态需要自定义 importer + nativeLibraryDir 命名技巧，复杂一个量级，
  仅在出现真实"进程内嵌 Python"需求时另立 `-runtime` 线；
- ssl：静态 OpenSSL；CA bundle 随包（Android 无 `/etc/ssl/certs`），`SSL_CERT_FILE` 注入；
- 命名 `libpython_cli.so`：Android 打包只认 `lib*.so`。

### 3.2 exec 型门禁 profile

与 `aosp-node-cli` 完全同 profile：ET_DYN（PIE）、PT_INTERP=`/system/bin/linker64`、
AArch64、DT_NEEDED 白名单、16KB、sha/size。由各仓自带的 `tools/provision.mjs` 强制。

### 3.3 构建链路（M1 实现；000-scaffold 固化接口）

1. `fetch-python-cli-source.mjs`：python.org 官方源码包，SHA-256 校验，不改源；
2. `build-python-cli-android.sh`：PEP 738 `configure --host=aarch64-linux-android`
   + 静态扩展 Setup + `-Wl,-z,max-page-size=16384` → make → strip → `libpython_cli.so`
   + stdlib assets；
3. `provision.mjs --out`：exec 门禁 → 投放 jniLibs + assets → META-INF 元数据。

开放问题（M1 拍板）：OpenSSL 交叉编译线的引入方式（vendored 独立 fetch）；启用哪些扩展
模块的首版集合（sqlite3/ctypes/_ssl/zlib 建议必选）；ensurepip 离线化。

## 4. 唯一事实源：`python-cli.lock.json`

## 6. 质量门禁汇总

| 门禁 | 判据 | 在哪强制 |
|---|---|---|
| ELF 形态 | ET_DYN（PIE）、PT_INTERP=系统 linker64、AArch64、16KB 对齐 | provision + CI |
| 依赖白名单 | DT_NEEDED ⊆ 系统库 + lock 登记库 | provision |
| 静态扩展 | 产物不携带独立扩展 .so（stdlib 资产内无 .so） | provision/assets 检查（M1） |
| 不入库 | jniLibs/**/*.so 与 assets 树被忽略 | .gitignore + review |
| 可复现 | 干净 runner 单条 workflow 重出同口径产物 | CI（M1） |
| 许可 | CPython PSF-2.0 + OpenSSL + wheel 许可 | THIRD-PARTY-NOTICES.md |
| 发布卫生 | RELEASE=false 默认；Token/GPG 不入库 | gradle.properties / publish |
